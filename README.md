# BasiDati-NoleggioDVD
Progetto per il Corso di Basi di Dati 2021-2022

In questo progetto è stato realizzato un database relazionale per la gestione di una catena di noleggio DvD. 

La progettazione è stata realizzate mediante una progettazione concettuale attraverso uno schema E-R a cui poi è seguita la progettazione logica con una stima teorica del volume dei dati e dei costi delle varie operazioni. Infine è stata effettuata la progettazione fisica su mariaDb. 
Per la fruizione della base di dati è stato sviluppato un semplice Front-End Cli in C.
